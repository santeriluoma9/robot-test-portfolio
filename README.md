# Test Automation Portfolio

[![Robot Framework tests](https://github.com/santeriluoma9/robot-test-portfolio/actions/workflows/robot-tests.yml/badge.svg)](https://github.com/santeriluoma9/robot-test-portfolio/actions/workflows/robot-tests.yml)

A small, working example of automated testing with **Robot Framework**, **Python** and a **CI pipeline** (GitHub Actions).
I built it to learn test automation hands-on and to have something concrete to show.

## What is tested

| Area | Target | Tooling |
|------|--------|---------|

Also included: a custom Python keyword library and a Bash helper script.
